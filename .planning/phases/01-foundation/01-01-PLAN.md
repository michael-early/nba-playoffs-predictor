<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer machine ↔ PyPI | `pip install` pulls third-party code from PyPI; supply-chain risk if a pin gets typo'd or unpinned |
| Developer machine ↔ GitHub (pre-commit repos) | `pre-commit` clones hook repos from GitHub at the rev specified in `.pre-commit-config.yaml` |
